# 打たない勇者

日本語の禁パチ・禁スロ支援アプリ。HTML / CSS / JavaScriptのみ。外部API、ログイン、実行時の外部依存はありません。初期履歴は空です。

## 開発と確認

Node.js 24、Python 3で確認しています。依存関係のインストールやビルドは不要です。

```sh
cd /workspace/utanai-yusha
node --test tests/core.test.cjs
python3 -m http.server 8000 --bind 127.0.0.1
```

静的サーバーでindex.htmlを開いて使用します。GitHub Pagesではブランチのルートを配信対象に指定できます。相対パスなのでリポジトリ配下でも動作します。公開操作は未実施です。

## 記録と計算

- localStorageキーは `utanai-yusha-v1`。端末・ブラウザ・配信元ごとに独立します。ブラウザの保存無効化、容量不足、破損は画面に通知します。破損データは自動上書きしません。
- JSON読み込みはバージョン、日付、状態、数値、メッセージ、タイマーを検証し、確認後に置き換えます。読み込み上限2MB、文章各2000文字、金額0〜1000万円。
- カレンダーは端末の現地日付を使用。達成率は全期間の記録日だけを分母とします。未記録で連続記録は途切れますが、過去の成功は保持します。
- 10分タイマーは終了時刻を保存。再読み込みやバックグラウンドからの復帰時にも実経過時間で再計算します。通知音はありません。終了後の強さは本人が入力します。
- 実際の節約額は自己申告累計。使わずに済んだ想定額は日額×打たなかった日数。積立試算は毎月末積立、年利/12の月利、税・手数料なしの仮定で、実績と分けています。
- 外部送信は行いません。相談先リンクを開くと外部サイトへ移動します。共有端末・JSONファイルの保管に注意してください。

## ブラウザ自動テスト

開発サーバー起動後、Python PlaywrightとChromiumがある環境で `python3 tests/browser.py` を実行します。このクラウド環境では導入済みです。テスト専用ブラウザで操作し、スクリーンショットは `/tmp/utanai-yusha-mobile.png` に出力します。
